The counts come from tenants.context_processors.platform_admin. `default_if_none`, not `default`: `default` also replaces 0, which would blank the count whenever the table is legitimately empty. This used to be marked up with Tailwind utilities (bg-white, p-6, rounded-xl, grid-cols-4, text-slate-400). The Django admin ships no Tailwind, so all of those did nothing and the tiles rendered as bare text. They are styled by admin.css now, which also has a dark-theme set. NB this must be a comment BLOCK, not a single-line {# ... #}: a Django {# #} comment is single-line only, so a multi-line one leaks its own text into the page. Comment blocks also do not nest, so this note deliberately avoids spelling the tag name literally. {% endcomment %} {% block content %}
